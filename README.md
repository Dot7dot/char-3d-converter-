# Char3D Converter · 2D → 3D 角色 / 物件引擎

上傳自己畫的 2D 圖片，轉換成可以放進 Web Game 的 **3D 三頭身角色** 或 **3D 物件**，並匯出成遊戲可用的檔案。
純前端靜態網頁（three.js），所有轉換都在瀏覽器內完成，圖片不會上傳到任何伺服器。

**線上版：** `https://dot7dot.github.io/char-3d-converter-/`

## 功能

- **三頭身角色**：頭 : 胸 : 腳 = 1 : 1 : 1，另有手臂；沒上傳的身體部位以預設形狀顯示。
- **每個部位 / 配件都有獨立上傳區**，且每個都支援 **正面 / 側面 / 背面 / 頂部** 四個視圖：
  - 身體：頭部、胸部（軀幹）、手臂（自動左右鏡像）、腳（下半身，可左右腿分開）
  - 配件：帽子、臉部配件、背部配件、右手持物、左手持物、腰部配件、鞋子（自動成對）
  - 物件模式：任何單一道具 / 物件
- **2D → 3D 轉換方式**（自動判斷，也可手動切換）：
  | 模式 | 適合 | 原理 |
  |---|---|---|
  | 膨脹 Inflate | 頭、身體、圓潤物件 | 依輪廓的局部粗細推算厚度（圓 → 球、細長 → 圓管） |
  | 擠出 Extrude | 武器、盾牌、翅膀、徽章 | 輪廓擠出成板狀並加圓角 |
  | 旋轉體 Revolve | 帽子、瓶罐、杯子 | 以正面輪廓繞垂直軸旋轉 |
  | 側面輪廓塑形 Profile | 有側面圖的角色部位（頭、身體、鞋子…） | 每一層的寬度取自正面、深度取自側面，截面為橢圓。兩張圖畫得不一致也不會破洞或被削掉 |
  | 三視圖雕刻 3-View Carve | 有側面/頂部圖的硬物件 | 正面 ∩ 側面 (∩ 頂部) 輪廓雕刻並圓角化，最精準 |
  | 平面 Plane | 髮絲、特效、紙片角色 | 雙面透明貼圖卡片 |
- 貼圖烘焙：模型自動展開成六個方向的 UV，把正面、背面、側面、頂部的原圖依表面朝向**混合烘焙**成一張貼圖，視圖交界沒有接縫，輪廓描邊也不會被拉長到側面。
- **面數預算**：每個部位自動減面（低模約 1,500／遊戲約 4,000／細緻約 10,000／原始），雕刻與變形都在高面數上進行，最後才減面。
- 自動去背（透明 PNG 或純色背景）、可調厚度、圓潤度、平滑、大小、位置、旋轉。
- 內建骨架節點與動畫：**Idle / Walk / Run / Jump / Wave**。
- 插槽（Sockets）：`Socket_Hat`、`Socket_Face`、`Socket_Back`、`Socket_Hand_R/L`、`Socket_Waist`、`Socket_Foot_R/L`，遊戲中可再掛載其他物件。

## 拍照 / 上傳後先裁切

每次選好或拍好照片，會先進入**裁切畫面**，確認範圍後才進行去背與 3D 轉換：

- 自動框住主體（最大的一塊），可拖曳角落或邊框調整、拖曳框內移動、在框外拖曳重新框選。
- 「旋轉」可把橫拍的照片轉正，「整張」不裁切，「自動框選」重新偵測。
- 取消就不會套用這張照片。
- 之後可按縮圖右下角的 ✂ 重新裁切（同一次使用期間會從原始照片重新裁）。
- 換了新照片或重新裁切後，這個視圖先前的對齊與修圖會重設。

## 手動調整（三視圖不吻合時）

- **對齊與修圖工作台**（卡片中「對齊與修圖…」），正面 / 背面 / 側面 / 頂部各一個分頁，三種工具：
  - **移動縮放**：背面鏡像疊在正面上比對（可調透明度、差異模式、自動對齊）；側面、頂部與正面並排，用參考線對齊高度與寬度。方向鍵微調、滾輪縮放。
  - **變形點**：輸入點數後按「生成變形點」，圖片輪廓上會平均出現那麼多個控制點；拖曳任一點，附近的圖跟著變形，其餘的點會固定住其他部分。可重複生成，在目前結果上繼續修。
  - **橡皮擦**：擦掉多餘的部分，擦掉的地方不參與 3D 成形。
  - 右側有 **3D 即時預覽**（可拖曳旋轉），每次修改後自動重新轉換；按「取消」會完全還原。
  - 所有修圖都是非破壞性的：以操作紀錄保存，隨時可復原或重設，原圖不會被改動。
- **視圖用途**：側面 / 頂部可設為「形狀＋貼圖」、「只用來塑形」或「只當貼圖」，避免畫得不一致的圖把形狀拉歪。
- **正交視圖 + 參考圖疊合**（視窗右下角，快捷鍵 1–5、0 回透視）：切到正 / 背 / 側 / 頂視圖時，選取部位的原圖會半透明疊在模型上，一眼看出哪裡沒對上。卡片「微調」分頁的「對照正面 / 對照側面」一鍵進入。
- **雕刻筆刷**（B）：直接在模型上拖曳捏塑。
  - 拉扯 (G)、鼓起 (I)、凹陷 (D)、平滑 (S)、壓平 (L)；`[` `]` 調大小，Shift 平滑，Ctrl 反向，可左右對稱。
  - 雕刻以「筆畫」保存，之後改厚度、品質或重新對齊時會自動重新套用。
- **3D 直接編輯**（視窗右上角，快捷鍵 Q / W / E / R / T）：
  - 移動、旋轉：拖曳部位的位置與角度（左右成對的部位會鏡像同步）。
  - 縮放：分別拉伸寬 / 高 / 深，配件會跟著重新貼合。
  - 變形籠：27 個（3×3×3）控制點，可拖曳做整體變形，預設左右對稱。
- **滑桿**：寬 / 高 / 深拉伸，上 / 中 / 下段的寬與深、前後彎曲、左右彎曲、扭轉。
- **單獨顯示** (H)、**置中** (F)、每個部位的顯示開關（眼睛圖示）。
- **復原 / 重做**：Ctrl+Z / Ctrl+Shift+Z。所有調整都會存進專案檔，並套用在每一種匯出格式。
- **自動儲存**：編輯內容會存在瀏覽器（IndexedDB），重新整理不會遺失；按「清除」重新開始。
- **3D 畫面固定顯示**：手機或窄視窗時，3D 畫面會釘在上方，往下捲動調整各部位時仍然看得到角色；可用「畫面大小」切換高度，「更多工具」展開動畫與視角列。

## 匯出格式

| 格式 | 說明 |
|---|---|
| **遊戲套件 ZIP**（推薦） | `character.glb` + `character.json` 描述檔 + `c3d-loader.js` 載入器 + `index.html` 可操作示範 + 貼圖 + 原始圖 + 專案檔 |
| GLB / glTF | 含貼圖、節點階層、動畫，Three.js / Babylon.js / PlayCanvas / Godot / Unity 通用 |
| OBJ + MTL | 靜態模型 + PNG 貼圖（Blender 等建模軟體） |
| STL | 3D 列印 |
| USDZ | Apple AR Quick Look |
| 2D Sprite Sheet | 8 方向 × 走路 4 格 PNG + JSON，給 2D / 俯視角遊戲 |
| 各部件分開 GLB | 每個部件 / 配件一個 GLB，可做換裝零件或獨立道具 |
| 專案檔 `.c3d.json` | 保存圖片與參數，之後可繼續編輯 |

座標規格：單位公尺、+Y 向上、正面朝 +Z、原點在腳底中央。

### 在遊戲中使用（three.js）

```js
import { loadCharacter } from './c3d-loader.js';
const hero = await loadCharacter('./character.glb');
scene.add(hero.object);
hero.play('Walk');
hero.attach('Socket_Hand_R', mySword);
// 每幀：hero.update(dt);
```

## 繪圖建議

1. 透明背景 PNG 最佳；純色背景會自動去背。
2. 每張圖只畫一個部位，置中。
3. 側面圖：角色面朝畫面**右側**；頂部圖：角色正面朝畫面**下方**。
4. 三視圖的上下邊界要對齊。
5. 不確定時先按「範例」看示範。

## 本機開發

```bash
python3 -m http.server 8000   # 然後開 http://localhost:8000
```

沒有建置步驟。three.js r170 放在 `vendor/three/`，減面用的 meshoptimizer 放在 `vendor/meshoptimizer/`（皆為 MIT License）。

## 檔案結構

```
index.html          介面
css/style.css       樣式（支援深色模式、手機版）
js/main.js          狀態、UI、預覽、匯出流程
js/imageproc.js     讀圖、去背、裁切、貼圖延展、輪廓距離場
js/converter.js     2D→3D 核心：距離場 → Surface Nets → 平滑 → UV 展開與貼圖烘焙 → 減面
js/deform.js        手動立體調整：拉伸、變形籠（FFD）
js/sculpt.js        雕刻筆刷與筆畫重播
js/align.js         對齊與修圖工作台（移動縮放、變形點、橡皮擦、3D 即時預覽）
js/imgedit.js       圖片修整引擎：橡皮擦、薄板樣條變形、輪廓取點
js/crop.js          拍照 / 上傳後的裁切畫面
js/surfacenets.js   等值面擷取
js/character.js     三頭身組裝、骨架節點、插槽、動畫
js/exporter.js      所有匯出格式與遊戲套件
js/samples.js       範例圖（程式繪製）
js/slots.js         部位 / 配件定義
```
