繪圖與三視圖指南
  1. 建議使用透明背景 PNG；純色背景也會自動去背（可調容差）。
  2. 每個部位只畫那個部位，置中、不要留太多空白。
  3. 正面必填；側面（角色面朝畫面右側）讓深度完全依照你的設計；背面提供背後貼圖；頂部（正面朝畫面下方）修正寬深。
  4. 三視圖的高度要對齊（同一個物件在各視圖中的上下邊界相同）。
  5. 只有正面時，系統會依輪廓自動推算厚度：圓的變球、細的變管、扁的用「擠出」。
  6. 帽子、瓶子等左右對稱的圓形物件，用「旋轉體」最準確。
  7. 前後或側面圖不完全吻合時，按卡片中的「對齊三視圖…」拖曳、縮放、旋轉各個視圖；或把側面 / 頂部設為「只當貼圖」。
  8. 修外形最快的方法：切到正 / 側 / 頂視圖，開啟參考圖，用雕刻 → 拉扯把輪廓拉到和原圖重疊。

操作說明

流程

  1. 圖片：在部位卡片上傳或拍攝正面圖（必填），有側面 / 背面 / 頂部就一起放。每次選好照片會先進入裁切畫面，框出要用的範圍再繼續；之後也能按縮圖右下角的 ✂ 重新裁切。按「對齊與修圖」可以移動縮放各視圖、用變形點修外形、用橡皮擦擦掉多餘的部分，旁邊有 3D 即時預覽。
  2. 成形：選轉換方式，調厚度、圓潤度。有側面圖時，角色部位預設用「側面輪廓塑形」，即使兩張圖畫得不一致也不會破洞。
  3. 微調：切到正 / 側 / 頂視圖，打開「參考圖」把原圖疊在模型上，再用拉伸、變形籠或雕刻筆刷把外形修到吻合。
  4. 擺放：調整大小、位置、角度。
  5. 儲存：按「儲存」把角色放進儲存庫，之後的變更會自動存進去。按「儲存庫」可以看到所有存起來的角色，選一個繼續編輯。
  6. 匯出：選格式下載。面數預算可在「專案設定」調整。

儲存庫

儲存庫是你的角色收納箱，做到一半的角色或物件都可以存在這裡。在電腦的 Chrome / Edge 上可以選一個資料夾，每個角色就是裡面的一個 .c3d.json 檔；手機、平板和其他瀏覽器則存在這個瀏覽器裡。已經存進去的角色，之後的變更會自動儲存。「匯入」可以放入專案檔或備份，「備份全部」會把所有角色打包成一個 ZIP。存在瀏覽器時，清除網站資料會一併刪除角色，請定期備份。

在模型上拖曳是雕刻；在空白處拖曳是轉動視角，右鍵拖曳平移，滾輪縮放。雕刻會保存下來，之後改厚度或品質也會自動重新套用。沒有存進儲存庫的編輯內容，也會暫存在這個瀏覽器，重新整理不會遺失。
